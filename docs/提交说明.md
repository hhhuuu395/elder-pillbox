# 提交说明

## 这个仓库包含什么

| 内容 | 位置 |
|---|---|
| 项目代码（后端 + 前端） | `app.py`、`static/index.html` |
| 接口回归测试脚本 | `curl_checks.sh` |
| 运行说明 | `README.md`（快速开始一节） |
| 复盘 | `docs/复盘.md` |
| 录屏分镜台本 | `docs/录制脚本.txt` |

## 不包含在仓库里的内容

**演示视频和 4 张截图随压缩包单独提交，不入库。**

原因是视频文件体积大，放进 Git 仓库会让仓库变得臃肿，也会拖慢每次 `git clone` 和 `git pull`。
这是刻意的取舍，不是遗漏。

这两项在压缩包里的位置和命名：

| 内容 | 文件名 | 说明 |
|---|---|---|
| 演示视频 | `学号-姓名-老人药盒助手-演示.mp4` | 时长 4-5 分钟，1920x1080 |
| 截图 1 | `01-老人端药历-早中两顿超时.png` | 老人端红框超时的药历 |
| 截图 2 | `02-子女端-漏服通知.png` | 子女端铃铛的漏服列表 |
| 截图 3 | `03-AI识别结果-警告色与删除按钮.png` | AI 抽取结果表单，含警告色与删除按钮 |
| 截图 4 | `04-确认生效-绿色横幅.png` | 人工补全确认后的绿色横幅 |

截图直接从演示视频里截取，不单独重拍。每张图的具体画面要求见压缩包里的
`截图/需求.txt`，视频的内容顺序要求见 `演示视频/需求.txt`。

## 想自己跑一遍

见 `README.md` 的「快速开始」一节，三步：

```bash
pip install -r requirements.txt
cp .env.example .env         # 然后填上自己的 DEEPSEEK_API_KEY
python -m uvicorn app:app --port 8000
```

没有 API Key 也能跑：两种异常演示档（`missing_fields` / `malformed`）是纯本地
mock，不走网络；真实调用档会提示未配置 Key，改用「+ 手动添加一条药」手工录入
即可走完整个流程。
