老人药盒助手 · 录屏台本（照这个念、照这个点）
============================================================
目标时长 4 分 45 秒左右（要求 4-5 分钟）
每一镜都列了：序号 | 窗口/页面 | 我做什么 | 屏幕上应出现什么 | 口播


■■■ 准备阶段（不录，录之前先做完）■■■
------------------------------------------------------------
P1. 启动服务，浏览器开两个标签页
      子女端  http://127.0.0.1:8000/
      老人端  http://127.0.0.1:8000/?view=elder

P2. 【子女端】底部「演示工具（dev）」→ 点「重置全部状态」
      然后把「AI 返回模式」设成  missing_fields（缺字段）

P3. 【子女端】dev 区反复点「− 120 分钟」，把虚拟时钟往回拨，
      拨到早上 6-8 点左右就停（看 dev 区显示的"虚拟时钟 HH:MM"）
      ★ 别拨过头跨到前一天

P4. 【子女端】先完整走一遍 AI 录入，把今天的药单造出来
      点「📷 拍照 / 选择图片」→ 补全红框里的必填项 → 点「确认并生效」
      （这一步只是为了"让老人端有药可吃"，不用录，随便补全能确认就行）

P5. 【老人端】点「🔄 刷新」，确认早上/中午/晚上三组药都出现了，
      状态都是「○ 待服用」

      ↓ 到这里才开始录屏 ↓

┌─ 01 ── 开场 ────────────────────────────── 20 秒（累计 0:20）
│ 页面：任意（建议停在子女端首页）
│ 我做什么：出镜 / 开始录屏，鼠标停在页面上
│ 屏幕上应出现：老人药盒助手的页面
│ 口播：「这是我做的老人药盒助手，给独居老人用的——老人这边按时吃药，
│         子女那边远程就能看到有没有漏服。」
└─────────────────────────────────────────────────────────

┌─ 02 ── 老人端药历 ──────────────────────── 20 秒（累计 0:40）
│ 页面：老人端（?view=elder）
│ 我做什么：什么都不点，鼠标从上往下慢慢划过药历
│ 屏幕上应出现：
│   · 顶部很大的时钟、「现在是「早上」时段的药」
│   · 早上 / 中午 / 晚上 三组，当前时段那张卡有蓝色粗边框和"现在"标签
│   · 每条药：药名、大号剂量、原定时间，状态「○ 待服用」，蓝色「已服用」按钮
│ 口播：「老人端字号特意做得很大，药名、剂量、时间都一眼能看清。」
└─────────────────────────────────────────────────────────

┌─ 03 ── 老人端打卡 ──────────────────────── 12 秒（累计 0:52）
│ 页面：老人端
│ 我做什么：在「早上」分组里，**只给一条药**点「已服用」
│           （建议点阿莫西林，它在中午也有一顿）
│           ★ 同组其他药、以及中午的药，全都别点——后面要靠它们变红
│ 屏幕上应出现：那一条变成「✓ 已服用 07:0X」，按钮消失
│ 口播：「早上这顿吃完了，点一下打卡，它会把具体时间记下来。」
└─────────────────────────────────────────────────────────

┌─ 04 ── 拨虚拟时钟 ──────────────────────── 20 秒（累计 1:12）
│ 页面：子女端（拉到页面底部）
│ 我做什么：展开「演示工具（dev）」，点「+ 120 分钟」约 3 下，
│           直到虚拟时钟显示 13:00 以后就停
│ 屏幕上应出现：「虚拟时钟 13:00（偏移 N 分）」
│ 口播：「真实场景要等好几个小时才看得出漏服，这里用虚拟时钟，
│         几秒钟就能把时间推到下午。」
└─────────────────────────────────────────────────────────

┌─ 05 ── 早中两顿变红超时 ────────────────── 15 秒（累计 1:27）

│   · 早上和中午的药变成**红色粗边框 + 红色「⚠ 已超时」标签**
│   · 按钮从「已服用」变成红色的「选择处理方式」
│   · 同时正中间弹出「⚠ 这顿药还没吃」
│ 口播：「时间一过，没吃的药就自动标红了——这就是漏服。」
│ ★ 这一帧就是截图①的素材，怎么截干净见文末"注意⑤"

┌─ 06 ── 漏服三选一 ──────────────────────── 22 秒（累计 1:49）

│ 我做什么：鼠标依次划过三个按钮，先别点

│   右下角还有「还有 N 条超时未处理」
│ 口播：「这里不是简单记一笔'没吃'就完了，老人有三种真实情况，
│         系统要分开处理。」

┌─ 07 ── 选「今天这顿没吃」 ──────────────── 10 秒（累计 1:59）

■■■ 注意（录之前扫一眼）■■■
------------------------------------------------------------
① .env 里是你的真 Key，录屏前确认浏览器和终端里都没有露出它。

② 第 4 镜拨时钟：只往未来拨 2-4 下就够，**别拨过午夜**——过了 0 点
   日期会翻到第二天，第二天的药全是"还没到点"，一条超时都看不到。

③ 第 3 镜只能给**一条**药打卡。要是把早上的都点完了，
   第 5 镜就没有"早中两顿红"了。

④ 第 8 镜的弹窗**没有关闭按钮**，只能一条条选完。
   所以超时了几条，就得处理几条。

⑤ 关于截图①（老人端早中两顿红色超时）——
   这个页面一刷新，只要有超时的药，就会自动弹出全屏遮罩的弹窗，
   而弹窗**关不掉**，所以红框永远会被一层 55% 的黑色遮罩压住。
   两个办法：
     简单版：直接截，红色透过遮罩还是看得见，勉强够用；
     干净版：按 F12 打开开发者工具 → 在 Elements 里找到 id="modalBg"
             那一行 → 右键 Delete element，遮罩消失后用 Edge/Chrome
             自带的截图（Ctrl+Shift+S）截页面。
             （遮罩只是个浮层，底下的红色超时状态是真的，不算造图）

⑥ 全片最容易忘的一句是第 14 镜那句"AI 只打草稿，人来签字"，
   这是整个项目的核心论点，尽量别念错。

⑦ 名字和学号记得替换：视频文件命名为
   学号-姓名-老人药盒助手-演示.mp4
